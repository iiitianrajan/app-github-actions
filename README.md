# Python GitHub Actions

A simple Python project created to learn and practice **GitHub Actions** and **Unit Testing**.

## Features

* Python application
* Unit testing with `pytest`
* Automated tests using GitHub Actions

## Run Locally

```bash
pip install -r requirements.txt
pytest
```

## GitHub Actions

Every push to the repository automatically runs the unit tests using GitHub Actions.

## Project Structure

```text
python-github-actions/
├── .github/
│   └── workflows/
├── tests/
├── app.py
├── requirements.txt
└── README.md
```
